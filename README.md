## A few things I’ve built

### [Sentinel-G](https://github.com/MelvinDenish/SME_Fraud_Detection) · [Live demo](https://sentinel-g-theta.vercel.app)
Graph-powered fraud analysis for SME financial statements. It combines **17 graph patterns**, deterministic rules, and ML detectors with an explainable evidence trail.

`Python` `FastAPI` `React` `Neo4j` `LightGBM`

### [PRISM](https://github.com/MelvinDenish/PRISM) · [Live demo](https://prismofficial.vercel.app)
A placement and interview-preparation platform with mentor discovery, live sessions, AI practice, shared coding rooms, and progress tracking.

`React` `Express` `MongoDB` `Socket.IO` `LiveKit`

### [Pre-Delinquency Intervention Engine](https://github.com/MelvinDenish/PreDelinquencyEngine)
A real-time early-risk platform built with a team for **Barclays Hack-O-Hire 2026**, where we finished **runner-up**. Streaming transaction events feed explainable risk signals and intervention workflows.

`Kafka` `Flink` `FastAPI` `XGBoost`

### [Business Entity Resolution](https://github.com/MelvinDenish/amazon-ml-challenge-2026)
A Python entity-resolution pipeline for the **Amazon ML Challenge 2026**. Team Bedrock recorded a **0.98674 leaderboard score**.

`Python` `Machine Learning` `Entity Resolution` `Data Pipelines`
